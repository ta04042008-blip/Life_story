# 試作用数値ルール v0.1

この文書の数値はゲーム用の初期調整値であり、歴史上の測定値ではない。実装時はこの版をルール版として固定し、調整内容を記録する。イベント原稿は events-initial.json を参照する。

## 1. 四半期と操作

- 1年をQ1〜Q4とする。地域ごとの季節・学期とは別に管理し、「四半期だから春」とは表示しない。
- 通常速度は1四半期8秒を初期値とし、1・2・4・8倍速を用意する。80年間の待ち時間は約43分で、選択・読書の時間は別。選択回答までの制限時間は設けない。
- 自動進行は時間の経過、おまかせは回答の自動化。「次の決断」は待ち時間だけを省略する。
- 未回答の選択があれば次の四半期に進めない。複数の決断は、生命・生活の緊急対応、期限のある進路、その他の順に処理する。
- 0〜5歳は養育者・環境の出来事として進める。本人の性格には加算しない。6歳以降は年齢相応の本人の選択を用意する。自立や学校へのアクセスは年齢だけでは決めない。

## 2. 出生時の値

| 項目 | 試作用の初期値 | 備考 |
|---|---|---|
| 健康 | 65＋一様乱数[-10,10]＋環境補正 | 疾患・障害は別状態として記録し、一律に能力不足と扱わない |
| 学び | 0 | 年齢に応じた学習の蓄積。発達段階を別に保持 |
| 魅力 | 50＋一様乱数[-10,10] | 乳幼児期は数値表示を控え、成人と同じ対人判定に使わない |
| 幸福感 | 50 | 幼少期は安心・養育環境として説明する |
| 生活資源 | 世帯テンプレートから算出 | 本人の能力と分離 |

環境補正の初期範囲は[-10,10]とし、データ未収録の項目は0にする。文化圏名だけで健康・学び・魅力を加減しない。世帯テンプレートの試作値は「不足20・不安定35・安定55・余裕75」の4段階を仮置きする。編集画面の出生プレビューに限り [ゲーム用仮値](data/birth-estimates.json) の構成比を使える。公開用の抽選比率はシナリオ別の出生データまたは明示した推定値で定義する。未定義の比率は根拠・幅・信頼度を記録したゲーム用推定で補える。推定値もない項目は均等抽選で隠さず、明示的に仮説値として設定する。

資源値は生活必要量に対する充足度の表示。食料・住居・金銭の実量は別で保持し、イベントの資源変化は表示値への暫定効果として扱う。経済モデルを収録後、同じ取引を実量と表示値へ二重加算しない。

## 3. 状態更新

- 値は小数1桁で保持し、0〜100に制限する。表示の丸めを再計算に使わない。
- 当期の合計効果は「環境効果＋選んだ行動＋出来事」。1つの行動につき毎回すべての値へ変化を付ける必要はない。
- events-initial.json の通常効果は概ね±1〜4点の暫定値。重大な出来事は別の条件付き効果として作成する。
- 学び・技能・魅力の正の獲得量は `元の獲得量 × (1 - 現在値 / 120)` として、高値での伸びを緩やかにする。健康・幸福・資源にはこの獲得式を適用しない。
- 幸福感はイベント効果の後、生活状態から算出する目標値へ差の10%だけ近づける。仮の目標値は `50 + 0.2×(健康-50) + 0.2×(生活資源-50) + 関係補正`。関係補正は支援・孤立・対立の状態から[-10,10]。文化圏の満足度統計を個人の幸福の確定値にしない。
- 学びは汎用的な知識、技能は分野別の熟練。読み書き、農作、手仕事などの技能IDはシナリオが定義する。同じ学び値でも可能な職業は技能・制度・境遇で異なる。

## 4. 行動の結果判定

実行資格は確率判定の前に確認する。存在しない学校・利用できない制度・移動不能な場所への行動は候補に出さない。

結果判定が必要なイベントでは、定義済み要素の0〜100の値を重み付き平均して得点Sとする。難しさDは30（取り組みやすい）、50（相応の準備が必要）、70（難しい）を初期案とする。

`成功確率 = clamp(1 / (1 + exp(-(S-D)/12)), 0.05, 0.95)`

例：修業の試験なら学び0.3・該当技能0.5・師の支援0.2。魅力をすべての判定に入れない。判定に必要な要素が未定義ならイベントは収録エラーとする。確率の上限・下限は、受験資格などの制度上の条件を突破するためには使わない。

失敗しても得られる経験・別の進路をイベント側に定義する。効果、結果の根拠、消費資源を記録する。通常の日常選択は確率判定を挟まず効果を反映してよい。

## 5. 人物・関係

- 初期の詳細人物は養育者・同居者を中心に最大8人。人数は家族の実人数を制限するものではなく、詳細シミュレーション対象の初期上限。
- 相関図の既定表示は重要人物12人。別一覧で全記録を見られる。新規生成は必要な出会いイベント時に行い、人物IDを固定する。
- 親密さ・信頼・緊張は0〜100。初期値は関係テンプレートが持つ。血縁だけで高い信頼を自動設定しない。
- 普段の交流は親密さ+1〜3、約束を守る行動は信頼+1〜3、対立は緊張+2〜5を初期案とする。複数軸を同時に変えてよい。
- 1年以上交流のない非同居の関係は親密さを年1点減らす試作案。信頼を同率で自動減少させない。死別した関係値は記録として保持する。

## 6. 選択から形成する性格

4軸の向きは仕様書の表の左を-1、右を+1とする。選択肢は関係する軸だけに[-1,1]のタグを持つ。単なる実行不可能・金銭不足による断念に、慣習重視などの性格タグを機械的に付けない。

- 日常の選択の重み1、大きな決断の重み3。
- 各軸に累積の方向値Eと証拠量Wを持つ。選択時に `E += 重み×タグ`、`W += 重み×abs(タグ)`。
- 軸表示値は `50 + 50×E/(8+W)`。証拠が少ない段階で極端な性格を決めつけない。
- 前の更新から経過した年数nに応じ、追加前にE・Wをともに `0.9^n` 倍し、最近の選択も反映できるようにする。
- Wが8未満の軸は「まだ定まっていない」。表示値40以下は左側、60以上は右側、間は「均衡」。
- 16通りの両端組み合わせを基本タイプとし、均衡軸を無理にどちらかへ割り当てない。試作は4語の組み合わせ表示（例：自律・挑戦・探索・計画）をタイプ名とし、固有の愛称は後から編集可能にする。
- タイプは15歳以降、少なくとも本人の有効な選択が20件ある場合に表示する。10年ごとの節目と人生終了時に当時の傾向を記録し、人物シートでは現在値を確認できる。
- おまかせで実行した行動も性格傾向へ記録するが、根拠に「おまかせ」を明記し、手動選択の証拠と区別して見られるようにする。

## 7. おまかせ

年間重点は生計・学び／技能・家族／関係・健康／安全。イベントの各選択肢に4分野それぞれの適合点0〜3、取り返しのつきにくい損失リスク0〜3を設定する。

実行可能な候補のうち重点の適合点が最大のものを選び、同点ならリスクが小さいもの、さらに同点なら保存済み乱数で選ぶ。隠された結果を事前に参照する最適解探索は行わない。将来の結果が分岐するイベントでも同じ方針を用いる。

## 8. 死亡率と将来予測

- 基準表は、満年齢 `x` から `x+1` までの一年死亡確率 `q_x` を優先する。死亡率 `m_x` や生命表の生存数 `l_x` を使う場合は、定義と変換式をレコードごとに保存し、値を `q_x` と読み替えない。
- 現代WPPから派生した初期表は年齢0–99を原系列とし、100歳以上は `q_98`・`q_99` のlogit傾向を延長した低信頼のゲーム用推定値を使う。99歳の実測率をそのまま延長した値ではない。歴史期は [ゲーム用推定表](data/mortality-historical-estimates.json) の100歳以上区分を使う。どちらも推定と表示し、死亡を固定年齢で確定しない。
- 一年確率を四半期へ均等配分する場合は `q_Q=1-(1-q_x)^(1/4)` とする。これは年内でハザードが一定という便宜的仮定である。年齢が一年未満の乳児は出生から次の誕生日までの期間に合わせ、季節性を使う場合は四半期ごとの条件付き確率を明示する。
- 年齢・暦年・場所・対象集団の対応する生命表を使う。平均寿命だけから年齢別死亡率を作らない。異なる年齢階級の間を補間する場合は、死亡確率のlogit上で行い、補間方法を保存する。
- 健康や生活資源によるリスク調整は、相対ハザード係数を用いて `q' = 1-(1-q_x)^HR` とし、`HR`、上下限、根拠をデータ版に記録する。根拠のない個人差を実測値として設定しない。
- 基準表が含む疾患・紛争リスクと個人イベントの即死判定を二重に加算しない。死亡モデルの要因とイベントの要因IDを対応させる。同じ四半期に複数のリスクを扱うときは、競合リスクとして処理するか、順序・条件付き確率を定義する。
- 人口予測と個人の死亡率の予測は同じデータとは限らない。予測系列の対象指標・年齢・年を確認し、未対応の指標はゲーム用仮説として記録する。
- 実測と推定を組み合わせた初期プレビューは、推定を含むゲーム用モードと明記する。史実の死亡率を完全再現するシミュレーションとは表示しない。

## 9. この初期案の収録範囲

状態更新・判定・関係・性格・自動回答の数値案は上記を使用可能。人口比、身分構成、出生環境、死亡率、貨幣換算は、データ不足なら幅を明示したゲーム用推定値で補える。初期イベントと推定値はゲーム用であり、実在人物の記録や特定地域の実測結果とは区別する。
