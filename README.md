# 巡る一生（Life_story）

西暦27年〜2026年のどこかに生まれ、四半期ごとにひとつの人生を最後まで歩む、成人向けの人生シミュレーション（ブラウザで動く、スマホ縦画面中心）。

## 遊び方・動かし方

ビルド不要です。ブラウザのモジュール読み込み（fetch）を使うため、ファイルを直接開かず簡易サーバー経由で開いてください。

```sh
python3 -m http.server 8000   # このフォルダで実行
# ブラウザで http://localhost:8000/ を開く
```

GitHub Pages では、リポジトリ直下をそのまま公開できます（`.nojekyll` あり）。

- 出生の年・地域・境遇は抽選で決まります。同じシードと同じ選択なら同じ人生を再現できます。
- 日常の選択は既定で「おまかせ」、大きな決断は自分で答えます（どちらも切り替え可能）。
- 保存は端末内（自動1・直前自動1・手動3・復元用1）。JSONの書き出し・読み込みもできます。

## テスト・検証

```sh
node --test tests/engine.test.mjs      # 通しプレイ・同一シード再現・保存再開の一致・二重回答防止
node tools/autoplay.mjs 1 20           # シード1から20人分を最後まで自動プレイ
node tools/build-mortality.mjs         # WPP 2024 の派生表を作り直す（通常は不要）
```

## 構成

| 場所 | 内容 |
|---|---|
| `spec/` | 受け取った仕様一式（原本のコピー。判断の根拠） |
| `data/impl/` | 実装側で書き下ろしたデータ（調整値・汎用舞台・追加イベント36件・舞台の対応表） |
| `data/derived/` | WPP 2024 から派生した年齢別死亡表 |
| `src/sim/` | ゲームのルール（画面に依存しない。ブラウザとNodeで同じコードが動く） |
| `src/ui/` | 画面（DOM・キャンバスの風景） |
| `docs/implementation-notes.md` | 実装メモ：仕様の解釈、決めたこと、既知の限界 |

## データと出典

- 1950年以降の年齢別死亡：国連 World Population Prospects 2024（CC BY 3.0 IGO）。`q_x` は生存数から派生（改変）しています。2024年以降は中位予測、2100年より先は2100年の表を据え置くゲーム用仮説です。
- それ以外（歴史側の死亡・機会・境遇・出生抽選の重み）は、低・中央・高の幅を持つ**ゲーム用推定**で、史実の測定値ではありません。画面にも表示されます。
- 出来事・選択肢・人物は本作のための創作です。外部のゲームの素材や文章は使っていません。
